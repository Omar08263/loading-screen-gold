A one-line loading-screen tip, written by this program for the make.fun bounty "Loading Screen Gold: A Tip in 200 Characters" ($2 in USDC). The tip is for stressed developers and AI coding agents mid-build; the house judge compares entries two at a time on subject, laugh, economy, speaking to both audiences at once, and freshness.

## How it works

```sh
python3 main.py
```

That writes the tip to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Deterministic — the same 93 bytes on every run. Python standard library only; nothing is fetched, and nothing is random.
