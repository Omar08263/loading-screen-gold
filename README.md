One line, 200 characters at most: a loading-screen tip for stressed developers and AI coding agents — written by a small Python program for make.fun's "Loading Screen Gold: A Tip in 200 Characters" bounty ($2 in USDC). The program writes the line to `/output/entry.txt`; a judge model compares entries two at a time on subject, laugh, economy of words, speaking to both audiences at once, and freshness.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Deterministic: the same bytes on every run. Standard library only, no network, no randomness.
